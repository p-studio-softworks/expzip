# Expzip

エクスプローラーライクなインターフェースで書庫を操作する、Windows 向けのアーカイバです。

> 開発初期段階です。まだ動作するアプリケーションはありません。

## 特徴

- **エクスプローラーライクなUI** — ツリービューとリストビューの2ペイン構成で、書庫をフォルダのように扱えます
- **インストール不要** — 単一の実行ファイルをコピーするだけで動作します。レジストリは変更しません
- **完全無償** — 業務利用を含めて無償で使えます

## 対応形式

| 形式 | 状況 |
|---|---|
| ZIP | 対応予定(最優先) |
| ZIP(AES-256 パスワード付き) | 対応予定 |
| 7z / tar | 対応予定 |
| LZH | 非対応 |

## 動作環境

- Windows 10 / 11 (x64)

## ビルド

.NET 10 SDK が必要です。

```
dotnet publish -r win-x64 --self-contained -p:PublishSingleFile=true
```
